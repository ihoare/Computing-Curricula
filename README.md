**CC2020（Computing Curricula 2020）是一份由ACM和IEEE计算机学会联合主导发布的全球性计算教育课程指南**，旨在为2020年代及以后的计算类本科专业提供前瞻性框架。它的核心是推动计算教育从“知识本位”向“能力本位”转型，强调培养学生面向职场和未来挑战的综合胜任力。

### 核心定位与目标
CC2020是2005年发布的CC2005的全面升级版，由ACM于2015年发起、2016年正式立项，历时数年完成。其目标有两个：一是产出一份全面的报告，描绘全球计算教育的图景；二是开发交互式可视化工具，帮助各类用户对比和分析不同的课程体系。

### 关键转变：从知识到胜任力
CC2020最根本的革新在于将教育焦点从传统的“知识本位”转向“**胜任力本位**”（Competency-Based Education）。它给出的胜任力公式是：
**胜任力 = 知识 + 技能 + 态度/品性**（Competency = Knowledge + Skills + Dispositions）。
这意味着，仅仅掌握“知道什么”（知识）和“知道怎么做”（技能）是不够的，还必须具备“知道为什么”的职业品性，例如职业道德、沟通意愿、责任感等，才能在实际任务中展现出完整的专业能力。

### 学科覆盖与全球视野
CC2020覆盖的计算学科范围比前版更广。除了计算机工程、计算机科学、信息系统、信息技术、软件工程外，还纳入了**网络安全**和**数据科学**等新兴领域。项目本身也强调全球包容性，其工作组代表了六大洲17个国家，意图打破以往课程指南以美国为中心的局限，为全球计算教育提供参考。

### 主要受众
报告明确服务于五类利益相关者：
- **未来学生及家长**：帮助理解不同计算专业之间的差异。
- **在读学生**：辅助选课或规划辅修。
- **行业雇主**：了解毕业生所学，以便招聘和培训。
- **教育工作者**：对照指南设计或改进课程。
- **教育机构与认证组织**：为课程认证和评估提供基准。
